Before → after · local control plane, free upstream pool, explicit fallback and human review

What Career Ops controls

  • Task classification and outer fallback chain
  • Local CV, profile, offers and review state
  • No automatic application submission
  • Explicit errors when all routes fail

What FreeLLMAPI controls

  • One OpenAI-compatible local endpoint
  • Healthy model/provider selection
  • 429/5xx cooldown and retry
  • Encrypted local credential database

Privacy reality

FreeLLMAPI runs locally, but anonymous inference is remote. Only selected prompt context is sent, yet upstream logging policies still apply. Use Ollama strict-local mode for offline/private inference.
